# 澎湃睡觉 · 梦境场景（公开演示版）

深蓝星空下，一张白色小床悬浮在翻涌的粉色火焰云海中——可交互的 WebGL2 梦境场景。

> 视觉原型致敬 Inigo Quilez 的 Shadertoy 经典作品
> [**Flames**](https://www.shadertoy.com/view/MsXGRf)（iq, 2013）。
> 原作代码版权较严（禁止再分发），故本仓库使用一段**原创占位火焰着色器**做演示，
> 不含任何原作代码；请前往原帖欣赏与学习真正的原作。

## 运行

- macOS：双击 `启动场景.command`
- 或手动：`python3 -m http.server 8642`，然后访问 <http://127.0.0.1:8642>

要求：支持 WebGL2 的现代浏览器；需联网加载 three.js（CDN）。

## 交互

| 操作 | 效果 |
|---|---|
| 按住拖动 | 左右环绕旋转 · 上下升降视角（松手保持角度，不回弹） |
| 单击火焰 | 整体色相偏移一步（循环） |
| 单击枕头 | 枕头漂浮 ⇄ 回位（四只独立，可多个同时漂浮） |
| ⚙ 参数 | 17 个实时滑杆：火焰浓淡 / 翻涌速度 / 走廊薄纱 / 口袋挖空 / 色相偏移 · 床大小 / 悬浮高度 / 原色饱和 / 漂浮高度 / 翻转幅度与速度 · 背景亮度 / 蓝调 / 深蓝底 · 暖光 / 蓝光 |

## 技术

- three.js（WebGL2 / GLSL ES 3.00）双通道渲染：
  ① 星空背景（cover-fit）+ PBR 床（顶点色可调饱和度）渲染到离屏纹理
  ② 体积火焰全屏 raymarch 叠加，背景色采样通道一画面 → 云雾自然缠绕床体
- 「走廊 + 口袋」密度场：沿视线挖出薄纱隧道与床周口袋，白床在浓厚云雾中若隐若现
- 相机与体积射线步进完全同步（拖拽松手后视角保持，继续缓慢漂移）
